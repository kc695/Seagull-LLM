# Seagull-LLM
Training &amp; Evaluating a small LLM that returns humourous quips from an input prompt

To read through this project, start at the Seagull Notebook Jupyter Notebook file attached. There you will see the planned infrastructure, the model's parameters, and the evaluation of the output using different methods.
Note: the artefacts are not uploaded due to its file size (It was trained on >2 epochs)
